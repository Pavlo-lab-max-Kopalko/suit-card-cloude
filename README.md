Мої віттання! Це тестове завдання Копалка Павла виконане згідно OOP принципів. 

Опис тестового завдання: https://docs.google.com/document/d/1QmMJFKJuCimfBu8jZ8_ER98E_Bv7w-Q-2ekyqvZOCHQ/edit?tab=t.0

Ось яким чином можна заустити проєкт без додаткових пакетів:

1. Виберіть папку де ви хочете зберігати копію проєкту, в терміналі запустіть:
``` git clone https://github.com/Pavlo-lab-max-Kopalko/suit-card-cloude.git ```
2. Вікдрийте проєкт, наприклад, запустіть в терміналі:
``` code suit-card-cloude ```
3. Щоб відкрити в браузері натисність в правомоу нижньому кутку Go Live. 
Якщо такої кнопки немає, тоді перейдіть у вкладку розширення (Extensions)
та встановіть Live Server.
Важливо: перевірте налаштування вашого ПК, щоб дізнатися в якому браузері 
по замовчуванню відкриється Live Server та змініть його на бажаний браузер.
